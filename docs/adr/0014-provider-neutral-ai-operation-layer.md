# Expose a provider-neutral operation layer for AI tools

The MVP will not require a built-in AI assistant. It will publish the Project Document schema and provide a headless CLI, backed by the same core as the web app, that validates, migrates, inspects, and atomically applies deterministic domain operations through files or standard input and output. External agents can add a Wall, move a Furniture Placement, or create a Design Proposal without browser automation or coupling to one AI provider.
