# Defer explicit Proposal Synchronization until after the MVP

Corrections to the Existing State will never silently alter an existing Design Proposal. The MVP leaves the proposal unchanged, marks it as based on an older Existing State revision with source revision and date, and provides no synchronization operation; the Homeowner may keep it or create a fresh proposal. A later version may add explicit Proposal Synchronization in which safe corrections apply automatically and competing edits require a Homeowner choice.
