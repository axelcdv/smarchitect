# Edit one Design Proposal at a time in the MVP

The MVP’s primary journey uses one Design Proposal, but a Project Document may contain several independent proposals. Homeowners can create each proposal by cloning the current Existing State, then rename, select, and delete it; the plan editor displays and edits only one at a time. Duplicating proposals, overlays, side-by-side views, automatic comparisons, and synchronization are deferred.
