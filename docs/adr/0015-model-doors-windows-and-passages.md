# Model Doors, Windows, and Passages explicitly

MVP Openings will include Doors with position, width, height, and either hinged or sliding operation; Windows with position, width, height, sill height, and fixed, hinged, or sliding operation; and unfilled Passages with position, width, and height. Hinged elements record hinge and swing direction, while sliding elements record slide direction; panel counts, pockets, tracks, hardware, and manufacturer-specific mechanics are deferred.
